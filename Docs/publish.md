Публикация Unity WebGL в Яндекс.Игры — чеклист

1) Версия Unity
- Рекомендуется LTS (например, 2021.3 LTS или 2022.3 LTS). Проверьте совместимость плагинов.

2) Подготовка проекта
- Установите Yandex.Games Unity SDK в проект.
- Настройте сцены: добавьте основную сцену (Main) в Build Settings → Scenes In Build.
- Player Settings → Other Settings:
  - Scripting Backend: IL2CPP
  - API Compatibility Level: .NET 4.x
  - Stripping Level: Medium (или по необходимости)
- Player Settings → Resolution and Presentation:
  - Default Canvas Width/Height при необходимости
  - WebGL Template: можно использовать Default, но мы будем патчить index.html в postprocess скрипте.

3) Сборка WebGL
- File → Build Settings → WebGL → Build
- Выберите папку для билда (например, Builds/WebGL)

4) Постобработка index.html
- Скрипт Assets/Editor/WebGLPostProcess.cs автоматически вставит подключение Yandex.Games SDK и контейнер для рекламы.
- При необходимости отредактируйте скрипт, чтобы вставлять ваш код инициализации SDK.

5) Сжатие и раздача
- Включите Compression Format: Gzip или Brotli в Player Settings → Publishing Settings.
- Сервер должен отдавать правильный Content-Encoding заголовок. GitHub Pages поддерживает gzip, но для корректной работы иногда нужен настройка сервера.

6) Тестирование локально
- Запустите локальный HTTP сервер в папке билда:
  - Python 3: python -m http.server 8000
  - Node: npx serve -s .
- Откройте http://localhost:8000 в браузере и проверьте работу SDK и рекламы.

7) Подготовка метаданных для Яндекс.Игр
- Иконки, скриншоты, описание на русском (README не заменяет метаданные в панели публикации).
- Возрастной рейтинг, категория.

8) Загрузка на платформу
- Используйте панель разработчика Яндекс.Игр, загрузите файлы билда и заполните метаданные.
- Тестируйте в контейнере/эмуляторе Яндекса при необходимости.

9) Советы по оптимизации
- Минимизируйте вес ассетов (текстуры, аудио). Используйте атласы и компрессию.
- Используйте Addressables или динамическую подгрузку для больших ассетов.
- Старайтесь укладываться в рекомендуемый размер бандла для быстрой загрузки.
