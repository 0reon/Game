Интеграция Yandex.Games SDK (Unity)

1) Официальный SDK для Unity можно найти на GitHub и в документации Yandex.Games — найдите "Yandex Games SDK Unity" (или "yagames sdk unity").
2) Установите SDK в проект Unity одним из способов:
   - Через Unity Package (если SDK поставляется как .unitypackage) — Assets → Import Package → Custom Package...
   - Или поместите папку плагина в Assets/Plugins/YaGames/
3) После установки в проекте должны появиться API для авторизации, рекламы и платежей.
4) Пример использования:
   - Инициализируйте SDK в начальной сцене (скрипт типа YaGamesManager), дождитесь готовности.
   - Используйте API SDK для показа рекламы, авторизации пользователя и сохранения прогресса.
5) Тестирование:
   - Сборка WebGL + локальный HTTP сервер (WebGL не работает через file://).
   - Вставьте примеры вызовов SDK в скрипты или в index.html (скрипты браузерной части) по документации.

Замечание: актуальная версия SDK и примеры лучше брать из официальной документации Yandex.Games.
