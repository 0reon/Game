# Game (Unity) — шаблон для публикации в Яндекс.Игры

Этот репозиторий — стартовая заготовка для Unity‑проекта, подготовленного к публикации в Яндекс.Игры. Репозиторий содержит служебные файлы, скрипт пост‑обработки WebGL и инструкции по интеграции Yandex.Games SDK.

Язык: русский.

Что включено:
- .gitignore и .gitattributes (рекомендации для Unity + Git LFS)
- Assets/Editor/WebGLPostProcess.cs — пример Editor скрипта, который патчит index.html после билда WebGL и вставляет подключение Yandex.Games SDK и контейнер для боковой рекламы.
- Assets/Plugins/YaGames/README.md — краткая инструкция по добавлению SDK в проект.
- Docs/publish.md — подробный чеклист построения WebGL‑билда и публикации на Яндекс.Игры.

Дальнейшие шаги (рекомендации):
1) Откройте Unity (рекомендуется Unity LTS: 2021.3 или 2022.3). Создайте новый проект или перенесите существующие Assets в эту структуру.
2) Установите Git LFS локально и добавьте крупные ассеты в LFS (png, jpg, wav, ogg и т.д.).
3) Установите Yandex.Games Unity SDK (см. Assets/Plugins/YaGames/README.md).
4) Настройте сцены и Player Settings → WebGL, затем соберите WebGL‑билд. После билда WebGLPostProcess автоматически патчит index.html.
5) Тестируйте локально через HTTP сервер и затем загружайте бандл на хостинг/панель Яндекс.Игр.
